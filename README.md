# microbit-attimuitehoi-createai
A guide to building an あっちむいてほい game with micro, using Create AI to recognize head movements.

> このページを開く [https://skytree-1.github.io/microbit-attimuitehoi-createai/](https://skytree-1.github.io/microbit-attimuitehoi-createai/)

## 手順

1. micro:bit Create AIに接続します。
  [micro:bit Create AI](https://createai.microbit.org/)

2. Cookie の設定画面が表示されるので、**（Manage cookies）** を選択します。

3. 画面を確認して **Essential cookies（always enabled)** にチェックが入っていて、**Analytics cookies** にチェックが入っていないことを確認して **（Save Setting）** を押します。
   
    Cookieの設定では、サイトの動作に必要なものと、利用状況の分析などに使われるものがあります。今回は、Essential cookies（サイトの動作に必要なもの）を許可して、Analytics cookies（分析に使われるもの）を許可しない設定にします。何でも許可するのではなく、サイトの説明を確認して選びましょう。

4. **新しいプロジェクト** をクリックして、自由に名前をつけて **プロジェクト作成** をクリックします。

![テスト](images/sc01.png)

5. 説明動画が表示されます。画面右下の **（接続）** をクリックして先に進みます。

![テスト](images/sc02.png)

6. 準備するものが表示されます。手元に全て揃っていることを確認して **次** をクリックして先に進みます。

![テスト](images/sc03.png)

7. USBケーブルをmicro:bitにつなげて、**次** をクリックして先に進みます。

![テスト](images/sc04.png)

8. 次のような説明が表示されるので、**次** をクリックして先に進みます。デバイスを選択するポップアップが表示されるので、手元のmicro:bitを選択して **(接続)** をクリックします。

![テスト](images/sc05.png)

9. 「データ収集プログラムのダウンロード」が始まります。これには数分かかる場合があります。

![テスト](images/sc06.png)

9. 画面の指示にしたがって、micro:bit の接続をとり、電池を繋ぎます。

![テスト](images/sc07.png)

10. 「パターンをコピー」に表示されているパターンと同じものが micro:bit に表示されていることを確認して **次** をクリックして先に進みます。

![テスト](images/sc08.png)

11. 「Web Bluetoothでmicro:bitに接続」の説明を読み **次** をクリックして先に進みます。

![テスト](images/sc09.png)

12. ペア設定をする画面で、手元の micro:bit を選び **ペア設定（Pairing）** をクリックします。

![テスト](images/sc10.png)

13. 「データ収集用micro:bitが接続されています！」というメッセージが表示されるので、説明を読みます（3ページあります）。

![テスト](images/sc11.png)

![テスト](images/sc12.png)

14. 3ページ目の説明の右下の **(閉じる)** をクリックして、アクションの登録に移ります。


![テスト](images/sc13.png)

15. アクションに名前をつけましょう。（ここでは上を向く動作ということで、仮に **up** と名づけました。）
16. ヘアバンドなどでペアリング済みのmicro:bitをおでこにつけてください。**(記録)** ボタンをクリックするとカウントダウンが始まるので、カウントダウン終了を確認して動作をします。

![テスト](images/sc14.png)

    ※ １つの動作に対して３回以上の記録が必要です。

17. 最初はガイドが表示されるので、確認して次へ進み、動作を登録してください。１つの動作を登録したら、「新しいアクション」をクリックして、下を向く動作も登録しましょう。
 
![テスト](images/sc15.png)

18. ２つ以上のアクションを登録したら。右下の「モデルをトレーニング」をくりっく。（これには少し時間がかかります。）
終わると、ツアーが始まるので、ツアーを読み進めます。ツアーが終わると、画面で、学習データの様子をチェックできます。実際に動作して確認してみてください。
![テスト](images/sc16.png)


19. テストをすると、なにもしていないときにも、up か down のいずれかの判定がされていることに気が付きます。
何もしていないという状態のアクションを追加するといいです。また、左右の動作も登録しましょう。

20. データを編集したり、他のアクションを追加するときは、左上の「←データサンプルを編集」をクリックして、データ収集画面にもどります。（15〜19をくりかえします。）

22. すべてのデータを記録してトレーニングして、確認ができたら右下の **(MakeCode で編集)**をクリックして、プログラム作成画面に移動します。

![テスト](images/sc17.png)

お疲れ様でした！
