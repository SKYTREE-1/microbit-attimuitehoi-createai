# microbit-attimuitehoi-createai
A guide to building an あっちむいてほい game with micro, using Create AI to recognize head movements.

> このページを開く [https://skytree-1.github.io/microbit-attimuitehoi-createai/](https://skytree-1.github.io/microbit-attimuitehoi-createai/)

## 手順

1. micro:bit Create AIに接続します。
  [micro:bit Create AI](https://createai.microbit.org/)

2. Cookie の設定画面が表示されるので、**（Manage cookies）** を選択します。

3. 画面を確認して **Essential cookies（always enabled)** にチェックが入っていて、**Analytics cookies** にチェックが入っていないことを確認して **（Save Setting）** を押します。
   
    Cookieの設定では、サイトの動作に必要なものと、利用状況の分析などに使われるものがあります。今回は、Essential cookies（サイトの動作に必要なもの）を許可して、Analytics cookies（分析に使われるもの）を許可しない設定にします。何でも許可するのではなく、サイトの説明を確認して選びましょう。

4. **新しいプロジェクト** をクリックして、自由に名前をつけて **プロジェクト作成** をクリックします。

![テスト](images/sc01.png)

5.説明動画が表示されます。画面右下の **（接続）** をクリックして先に進みます。

![テスト](images/sc02.png)

6.準備するものが表示されます。手元に全て揃っていることを確認して **次** をクリックして先に進みます。

![テスト](images/sc03.png)

7.USBケーブルをmicro:bitにつなげます。
